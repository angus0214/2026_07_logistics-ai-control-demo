# 0004. 行動裝置響應式策略 (RWD)

## 狀態
Accepted (2026-08-20)

## 背景脈絡 (Context)
Logistics AI Control Tower 需要支援手機與平板的響應式版面。這個應用有複雜的 B2B 元件：左側導覽列、中間的資料處理區（表格／聊天），以及右側的 OCR 文件預覽面板 (`w-[500px]`)。原本的版面是固定的水平 flex 排列，在手機上造成嚴重的水平溢出，幾乎無法使用。

## 決策 (Decision)
我們採用以下行動版面策略：

1. **左側導覽列**：
   - 策略：**Off-canvas Drawer（側滑抽屜）**。
   - 理由：手機的水平空間連迷你側欄都放不下。在手機和平板上預設隱藏，由頁首的漢堡選單開關；在桌面（`md:` 斷點以上）維持固定的左欄。

2. **右側面板（文件預覽）**：
   - 策略：**Modal/Sheet Overlay（全螢幕覆蓋層）**。
   - 理由：如果改成垂直堆疊，使用者得捲過很長的資料表才看得到文件。改為在手機上以全螢幕覆蓋層呈現，由手機頁首的「查看文件」按鈕開關；在大型桌面（`xl:` 斷點以上）維持固定的右欄。

## 後果 (Consequences)
- 版面結構使用響應式的 Vue 綁定 (`ref(false)`) 與 Tailwind 斷點工具 (`md:`、`xl:`)。
- 子頁面不需要自己處理響應式，由版面外層統一管理抽屜／覆蓋層的狀態與 CSS 轉場。
